# Little Diesel: adversarial journey review

10November2026. Scope: user feedback16:31, guided path and bugs. Preserve current warm hand-inked clay geometry, not a new visual skin. Production remains unchanged until proof review.

## Confirmed problems

- Arrival has three equal modes; Meet it reselects the existing mode with no meaningful transition. No clear reason or next learning action.
- Peek inside explodes parts, reserves multiple empty text/control bands, then refits the camera each frame with a minimum distance. Model gets smaller and user zoom is overridden.
- Parts connector is suppressed whenever a visibility/path test meets another interior mesh. Selected piston has no connector in the live browser; crankshaft is the user's reported visible exception.
- Question/reasoning phases make the canvas inert and skip scene rendering, replacing it with text. Learner cannot see the mechanism while predicting or reading.
- Switching modes recreates lesson state, so optional exploration loses progress. The select exposes only six labels even though nine parts are tappable.
- Existing separate banners, hints, reasoning screens, mode strip and more controls accumulate different navigation rules. No stable shared model/text/action layout.

## Proof

One learner-paced sequence: meet one cylinder, predict/watch intake, compression, power, exhaust, transfer question, explain the cycle. Existing question and feedback meaning preserved. One large current title/explanation beside a large model at desktop; phone keeps the model visible above a scrollable current explanation. No autoplay on load. No dead Meet it action, competing mode strip or separate Make it go page.

Optional Look at parts one by one keeps the assembled cutaway, includes nine components, selected highlight plus anchor dot/diagram leader. Diagram line explicitly is not a fluid/force path and may pass in front of parts. Camera fit runs only on resize/reset; user orbit and zoom remain free in lesson and exploration. Returning restores question/answer phase. One part at a time, three choices maximum, no all-parts label cloud.

Next is the primary action. Back, play/pause, reset and full screen have accessible names. Fullscreen includes model and current guide, with viewport fallback. Extra explanation/model limits are disclosed. Existing spring feel retained for feedback; press .97/120ms, feedback240ms and instant reduced-motion UI are small context-fit tuning, not a fleet rollout.
